# Бюджет — Сбер / Альфа / Озон

Личный трекер бюджета по методу 50/30/20. React + Vite, устанавливается как
PWA (иконка на телефоне), данные хранятся в `localStorage` браузера — ничего
не отправляется на сервер.

## Быстрый старт (локально)

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Публикация на GitHub Pages

1. Создайте новый **пустой** репозиторий на GitHub (без README, без .gitignore —
   они уже есть в этом проекте).
2. В папке проекта выполните:

   ```bash
   git init
   git add .
   git commit -m "Первая версия бюджета"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. На GitHub откройте **Settings → Pages** репозитория и в поле **Source**
   выберите **GitHub Actions** (не "Deploy from a branch").
4. Готово — при каждом `git push` в `main` workflow из
   `.github/workflows/deploy.yml` сам соберёт проект и опубликует его.
   Через 1–2 минуты сайт появится по адресу
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`
   (ссылку также можно увидеть на вкладке **Actions** после того, как
   workflow завершится, либо на самой странице Settings → Pages).

## Установка на телефон

Откройте опубликованную ссылку в браузере на телефоне:

- **Android (Chrome):** появится баннер «Установить приложение», либо
  через меню (⋮) → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран «Домой»».

Появится иконка, которая открывается как обычное приложение, без адресной
строки браузера.

## Важно про данные

Все операции хранятся в `localStorage` **этого конкретного браузера на этом
устройстве**. Это значит:

- Если открыть сайт в другом браузере или на другом телефоне — там будут
  свои, отдельные данные (это не облачная синхронизация).
- Очистка данных браузера/сайта удалит и записи в приложении.
- Если хотите видеть одни и те же данные на нескольких устройствах — самый
  простой вариант: пользоваться приложением только в одном браузере (или
  добавить синхронизацию через какой-нибудь бэкенд/базу данных отдельным
  шагом — например, Firebase/Supabase — это уже выходит за рамки статического
  GitHub Pages сайта).

## Структура проекта

```
src/
  App.jsx        — всё приложение (дашборд, добавление операций, накопления,
                    анализ, настройки)
  storage.js     — обёртка над localStorage
  main.jsx       — точка входа React
  index.css      — Tailwind + шрифты
.github/workflows/deploy.yml — автосборка и публикация на GitHub Pages
```

Чтобы поменять стартовые суммы (зарплата, авансы, переводы, цель подушки)
без пересборки — просто откройте вкладку «Настройки» в самом приложении,
менять код не нужно.
