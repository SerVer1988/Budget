# Бюджет — Потребности / Хотения / Сбережения

Личный трекер бюджета по методу 50/30/20 (Сбер / Альфа / Озон). React + Vite,
устанавливается как PWA (иконка на телефоне). Данные хранятся в облаке
**Supabase** (вход по почте и паролю), поэтому одни и те же записи доступны
на всех ваших устройствах. Копия данных кэшируется в `localStorage`, так что
приложение открывается и без интернета, а изменения, сделанные офлайн,
отправляются, когда сеть появится.

## Быстрый старт (локально)

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Как устроены данные

- Таблица `app_data` в Supabase: `user_id`, `key`, `value`, `updated_at`.
  В ней два ключа на пользователя: `settings` и `transactions` (JSON).
- Запись «условная»: если те же данные успели изменить на другом устройстве,
  старая версия их не затрёт — приложение покажет плашку «обновить».
- Доступ к строкам ограничен правилами RLS: каждый видит только свои данные.

## Настройка Supabase

1. В проекте Supabase создайте таблицу `app_data` с колонками `user_id uuid`,
   `key text`, `value text`, `updated_at timestamptz` и составным первичным
   ключом `(user_id, key)`.
2. Откройте **SQL Editor**, вставьте содержимое файла
   [`supabase-security.sql`](./supabase-security.sql) и нажмите **Run** — это
   включит RLS и создаст правила доступа.
3. Адрес проекта и публичный (publishable) ключ прописаны в `src/storage.js`.
   Публичный ключ можно хранить в коде: защита данных обеспечивается RLS.
4. Если приложением пользуетесь только вы, отключите регистрацию новых
   пользователей: **Authentication → Sign In / Providers → Email → Allow new
   users to sign up** (после того, как создадите свою учётную запись).

## Резервная копия

В **Настройки → Данные**:

- **Резервная копия (JSON)** — все настройки и операции одним файлом;
- **Таблица (CSV)** — операции для Excel (разделитель «;», UTF-8);
- **Восстановить из копии** — загрузить ранее сохранённый JSON (текущие данные
  заменяются после подтверждения).

## Публикация на GitHub Pages

1. В **Settings → Pages** репозитория выберите **Source: GitHub Actions**.
2. При каждом `git push` в `main` workflow `.github/workflows/deploy.yml`
   собирает проект и публикует его. Через 1–2 минуты сайт доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

## Установка на телефон

- **Android (Chrome):** меню (⋮) → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран «Домой»».

## Структура проекта

```
src/
  App.jsx        — всё приложение (дашборд, добавление операций, накопления,
                    анализ, настройки)
  storage.js     — облачное хранилище на Supabase: вход, кэш, офлайн-очередь
  main.jsx       — точка входа React
  index.css      — Tailwind + шрифты
supabase-security.sql        — правила RLS для таблицы app_data
.github/workflows/deploy.yml — автосборка и публикация на GitHub Pages
```
